# 📚 LibraNet – Library Circulation and Reader Analytics

## Project Overview

LibraNet is a Library Circulation and Reader Analytics system developed to manage library records and analyse reader activities using database technologies and data analytics tools.

The project combines MySQL, Python and MongoDB to demonstrate relational database management, data analysis, visualisation and NoSQL operations.

## Technologies Used

- **MySQL:** Database creation, data management, analytical queries and triggers.
- **Python:** Database connectivity and data analysis.
- **Pandas:** Data manipulation and analysis.
- **Matplotlib:** Data visualisation.
- **Seaborn:** Statistical visualisation.
- **MongoDB:** Document storage, CRUD operations and aggregation.
- **Jupyter Notebook:** Python development environment.

## Project Modules

### 1. MySQL Database Management
- Database and table creation.
- Relational database design.
- Data insertion and management.
- Analytical SQL queries.
- Automatic fine calculation using triggers.

### 2. Python Data Analysis
- MySQL database connectivity using DB-API.
- Data extraction using Pandas.
- Data cleaning and analysis.
- Visualisation of library activities.

### 3. MongoDB Implementation
- Database and collection creation.
- Document insertion and retrieval.
- Update and delete operations.
- Aggregation pipeline for reader analytics.

## Key Analytics

- Most borrowed books.
- Popular authors.
- Category-wise borrowing.
- Late book returns.
- Fine collection and outstanding amounts.
- Monthly borrowing trends.
- Book availability.
- Most active members.
- Publisher-wise book distribution.
- Average borrowing duration.
